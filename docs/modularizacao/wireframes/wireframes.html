Regras desta tela

  1. 1O seletor só renderiza com 2 ou mais módulos visíveis; o nome do módulo fica ao lado do logo.
  2. 2O core nunca aparece como módulo. Módulo desativado some do seletor.
  3. 3A escolha é lembrada no navegador; o padrão é o primeiro módulo visível (modulo_padrao).
  4. 4Sem cor própria: só a cor da operação continua mudando o tema.

Quem vê o quê (matriz do plano)

  2. Gestor: RH · Operação (seletor)

  4. Analista, DP, Estagiário: só RH · Supervisor, Control Desk, Qualidade, Operador: só Operação · Funcionário: só o essencial (core)

Notas

  1. 1Menu da Tecnologia é todo administração, em poucos grupos: Acessos (Usuários, Perfis e permissões, Operações), Sistema (Módulos, Integrações, Configurações globais), Auditoria. Escalas e Plantões é a tela emprestada do WFM, filtrada pela operação TI. Abaixo de 1200 px o menu vira só ícones, como hoje.
  2. 2Módulos protegidos mostram o interruptor travado — não há como se trancar para fora.
  3. 3O botão do WFM exige confirmação; com a variável de ambiente definida ele fica desabilitado e explica o porquê (transição de homologação).
  4. 4Cards de administração são links para as telas já existentes (Usuários, Perfis, Operações, Logs…) reorganizadas sob este módulo; novas: Módulos, WFM e Integrações (somente status, sem segredos).

Estados

  1. Módulo desativado: interruptor desligado, tag “desativado”, aviso do que deixa de funcionar.
  2. Sem permissão de editar (configuracoes.editar): interruptores e botão viram somente leitura.
  3. Erro ao salvar: mensagem inline no cartão, valor volta ao anterior.
